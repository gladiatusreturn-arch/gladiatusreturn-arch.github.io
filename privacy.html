YouTube API Services

ClipForge uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies to the Google data involved. The tool accesses the operator’s YouTube channel only to upload videos and read their statistics; it does not store YouTube user data about anyone else. Access can be revoked at any time at the Google security settings page.

TikTok

ClipForge uses the TikTok Content Posting API to post videos to the operator’s own TikTok account and to read their statistics. Access can be revoked at any time from the TikTok app under Settings and privacy → Security & permissions → Apps and services.
